## Формат номера РФ
Номер должен соответствовать формату: 
- Буква (только А, В, Е, К, М, Н, О, Р, С, Т, У, Х)
- 3 цифры
- 2 буквы
- 2 или 3 цифры региона

Примеры: А123ВС77, А200БВ124, В777АА99
